# 🏛️ 鲁迅数字人 · 双模式对话系统

面向 **广州鲁迅纪念馆** 的在线体验 Demo。游客可以跟「鲁迅」语音/文字对话，也可切换讲解员模式了解场馆。

## 两种模式

| 模式 | 触发（自动识别） | 回答内容 |
|------|-----------------|---------|
| 🏛️ 讲解员模式 | 问场馆/展品/参观信息 | 专业、克制的讲解风格 |
| 🎭 鲁迅数字人 | 问鲁迅生平/作品/思想，或称呼「您」 | 以鲁迅口吻（半文白、冷峻、反讽）作答 |

系统内置 **5 层越界防护**：意图分类 → 查询改写 → 多子查询检索 → 时间边界（1936）→ 质量守卫（幻觉检测 + 一致性校验），确保「鲁迅」不说现代的事、不编造事实。

## 试试这样问

- 这个展厅主要展什么？
- 鲁迅先生，您为什么要弃医从文？
- 您和许广平是怎么认识的？
- 介绍一下《狂人日记》

> 右侧「调试面板」会实时展示意图判定、检索结果、质量守卫状态——方便评审时看到整条 RAG 链路在运转。

## 技术架构

- **LLM**：DeepSeek 云端 API（`deepseek-v4-flash`，thinking=disabled）
- **Embedding**：`BAAI/bge-small-zh-v1.5`（首次冷启动自动下载，约 100MB）
- **向量库**：ChromaDB（`chroma_db/` 随 Space 提交，348 条知识 / 399 chunks）
- **检索**：多子查询语义检索 + 去重合并
- **质量守卫**：幻觉检测 + 一致性校验 + 重试/兜底
